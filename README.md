#  MEZZ DOWNLOADER

## Installation

1. Ouvrez le dossier **MEZZ DOWNLOADER**.

2. Cliquez dans la barre de chemin de l'Explorateur de fichiers, tapez :

```
powershell
```

puis appuyez sur **Entrée**.

3. Installez les dépendances avec cette commande :

```powershell
pip install -r requirements.txt
```

4. Une fois l'installation terminée, lancez le programme avec cette commande :

```powershell
py Mezz.py
```
