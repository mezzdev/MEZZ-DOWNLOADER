# MEZZ DOWNLOADER

## Installation

1. Clonez le dépôt avec Git :

```powershell
git clone https://github.com/xMezz0/MEZZ-DOWNLOADER
```

2. Ouvrez le dossier **MEZZ DOWNLOADER** :

```powershell
cd MEZZ-DOWNLOADER
```

3. Cliquez dans la barre de chemin de l'Explorateur de fichiers, tapez :

```powershell
powershell
```

puis appuyez sur **Entrée**.

4. Installez les dépendances avec cette commande :

```powershell
pip install -r requirements.txt
```

5. Une fois l'installation terminée, lancez le programme avec cette commande :

```powershell
py Mezz.py
```
